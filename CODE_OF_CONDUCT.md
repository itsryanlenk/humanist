# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
in full. The canonical text lives at that link and is not duplicated here, so that
the version this project follows can never drift out of step with the version it
claims to follow.

## Scope

The Covenant applies in every project space and in public spaces where someone is
representing the project.

## Reporting

Report a concern through this repository's [private security advisory form](../../security/advisories/new),
which is confidential and visible only to the maintainers, or by opening an issue
if the matter is not sensitive. Reports are handled by the maintainers, who will
respect the privacy of the reporter.

Enforcement follows the Covenant's Enforcement Guidelines, including its four-tier
ladder from correction to permanent ban.
